Matchup dengan bukti langsung

SAMPEL ≠ KEPASTIAN

Urutan: matchup ≥12 bola sah, lalu economy langsung. Kondisi pitch, handedness, kualitas lawan, line/length tanpa anotasi, dan kesiapan fisik belum diketahui. Bukan prediksi hasil.

Match setup

Urutan nama = urutan awal batting. Nama tim + nama pemain menjadi identitas lintas match; gunakan ejaan konsisten. Match aktif akan diarsipkan otomatis saat membuat match baru.

Extras, wicket & anotasi

Wide: runs = tambahan di luar penalti 1. No-ball: runs = runs bat; bye/leg-bye tambahan pada kolom terpisah. Tidak boleh keduanya.

Run-out: pilih batter out dan atur end sesuai keputusan umpire. Caught: striker baru menghadapi bola berikutnya kecuali over selesai.

Data & arsip

CADANGAN LOKAL • GUNAKAN MENU DATABASE UNTUK SIMPAN AKUN

Cadangan browser selalu lokal. Untuk menyimpan ke akun, gunakan menu Database setelah login dan pengaitan roster. Ekspor JSON untuk cadangan lengkap. Impor divalidasi sebelum data diubah.

Mendukung JSON Match Analyst (termasuk rencana), JSON satu rencana, match/arsip V6.4 dan backup lokal V6.4. CSV hanya memuat pertandingan. CSV harus memakai format ekspor Match Analyst (memuat metadata tim dan aturan).

Arsip tersimpan

Snapshot dengan ID yang sama diperbarui; Combined mengutamakan match aktif dan menghapus salinan identik. V6.4 asli tersedia terpisah dalam paket unduhan.

Akun pencatat

Statistik publik bisa dibaca tanpa akun. Login diperlukan untuk menyimpan pertandingan ke database dan mengakses taktik milik Anda.

Aktivasi pendaftaran email umum masih menunggu konfigurasi pengirim email verifikasi oleh pengelola.

Tim dan hak pencatatan

Buat tim baru atau minta kode undangan dari pengelola tim yang sudah ada. Login saja tidak memberi hak menulis hasil untuk seluruh tim.

Database pemain publik

Profil memakai ID tetap. Statistik berasal dari hasil yang telah diterbitkan pencatat, bukan verifikasi resmi kompetisi.

Database pertandingan & taktik

Data lokal di browser

Draft pertandingan dan rencana hanya untuk akun pemilik. Publikasi hasil hanya tersedia setelah kedua innings selesai dan ID seluruh pemain terhubung. Catatan delivery dan rencana taktik tidak ikut diterbitkan.

Mengaktifkan opsi ini berarti ringkasan hasil dan statistik pemain akan menjadi publik saat match berakhir. Riwayat mentah dan taktik tetap privat.
